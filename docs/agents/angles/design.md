# Angle: design

What the user sees and does: screens at the project's breakpoints, states (empty, loading, error, success), copy in every supported language, keyboard and screen-reader access, consistency with the project's design system. Evidence is a screenshot or a scenario in the evidence pack. A broken flow is a `blocker`; an inconsistency is a `should-fix`; a wording or spacing issue is a `nit`.
