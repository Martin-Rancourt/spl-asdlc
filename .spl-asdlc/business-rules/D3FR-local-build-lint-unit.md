# D3FR — Before readiness, run only the local build, lint and unit tests.

Status: Proposed

## Rule

Integration, visual/UI, database/data suites and specialist reviews belong in PR CI or QA. Do not run those as an implementation preflight.

## Evidence

Owner’s decisions of 2026-10-27, ASDLC-NN5K (parallel PRs, phase 1).

## Test

No executable enforcement claimed yet; the remaining repository/release migration stays in ASDLC-NN5K.
